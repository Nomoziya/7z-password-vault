# 1.6.0 正式版发布说明

本版在密码管理设置页加入“恢复上一版本…”。程序先验证同目录 `.bak` 的 v4 加密格式和完整性，显示确认信息，保留恢复前的加密文件，然后原子替换当前库。备份可能包含已删除条目；旧主密码备份需要原密码，DPAPI 备份受原 Windows 账户约束。恢复前请关闭旧版程序。

恢复取消、密码错误、文件占用、权限拒绝和磁盘满时，不提交恢复；启动时发现上次留下的恢复临时文件会提示检查，不自动采用。清理失败和文件已恢复但设置更新失败会分别提示。

**验收范围：Windows 11 Insider x64 build 26220。** 普通桌面与独立标准账户分别完成完整 GUI 436/436；三种语言恢复专项各 45/45，简体中文还在标准账户 200% 缩放下完成完整测试。核心压缩 39/39、运行时输入 10/10、发布门禁 34/34；原生安全、真实 ACL、跨账户 DPAPI、一次性 VHD 实际磁盘满和 v1.5.0 升级回滚有独立记录。其他 Windows 版本和未测缩放不在本次验收范围。验证证据见 [恢复验收记录](restore-final-validation.md)。

便携 ZIP 不带安装器、卸载器或用户密码库。两个 EXE 未签名，Defender 状态为 `not-reviewed`，未提交样本复核；不能据此宣称扫描通过或不会误报。随包 `.sha256`、包内 `SHA256SUMS.txt`、`.build.json`、`.source.sha256` 和 `.sbom.json` 用于完整性及构建记录核对，不能代替发布者数字签名。应从可信的项目发布页取得本版哈希。

对应源码按本版 Git 标签归档；构建需要 `BUILD.md` 指定的上游 7-Zip 26.03 源码归档和八个固定运行时文件，源码 ZIP 不包含这些第三方二进制或编译器。两个 GUI EXE 与已在标准账户验收且从干净提交独立重建的开发版逐字节一致。本版打包记录另附确切源码提交和哈希。
