## 本轮变更

- 未指定库位置时，只有便携和 APPDATA 两个实际文件都存在才询问；只有一个时直接选用，目录不当作库文件。
- 设置页失败、取消和异常退出清除主密码缓存；显示错误前也清除。底层 Save 失败统一清除缓存并回滚条目。
- 覆盖现有库前，将锁内读取的上一代原始密文写入独占临时文件、刷盘，再替换 `.bak`，最后替换主文件。首次创建无备份。备份失败中止保存；主文件最终替换失败时备份可能等于仍有效的原文件。只保留一代，不自动恢复。
- 默认运行时从 dist 最新 internal-test ZIP 获取，验证外部哈希、ZIP 路径白名单、包内清单；无包或坏包明确失败。部署仍校验冻结运行时哈希和上游归档哈希。
