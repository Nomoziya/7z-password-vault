## 新增 / New

- **程序目录被移动时会发现并修正**：便携副本被拷到别处或改名后，快捷方式与「应用和功能」里的卸载登记还指向旧目录。现在程序启动时会比较记录（`HKCU\Software\7-Zip\PasswordVault\LastRegistered`）与当前目录：
  - 旧目录里**还有另一份拷贝**（`7zFM.exe` 仍在）→ 判定为「另一份副本」，**不提问、不抢占**它的快捷方式与卸载项；
  - 旧目录**已消失** → 先核对那条卸载项确实指向旧目录（别人的登记一律不动），再静默删除这条死登记，然后**每次移动只问一次**是否把快捷方式与卸载项更新到当前位置；选「否」就是答复，不再打扰。
- **设置页新增按钮「创建快捷方式 / 登记卸载...」**（工具 → 选项 → 密码管理器）：首启询问答了「否」或想换目录时，随时可以一点完成；它是动作按钮，不参与「确定 / 取消」的提交语义。
- 另一份拷贝仍在使用同一名称或登记时，**绝不覆盖**它，而是把那份拷贝的目录告诉你（提示文案含具体路径）。

## 有意保留的边界 / Deliberate limits

- 从**临时目录**、**可移动盘 / 网络盘**或**超长路径（≥200 字符）**启动时不会自动提议登记：指向 U 盘的卸载项与快捷方式会随介质消失。设置页按钮仍可显式登记。
- 首启询问答「是」但系统策略拦住了写入时，不会记录「已登记」，也不会每次重问——重试用设置页按钮。
- 极端路径拼写（结尾带点/空格等）未做归一化；`HKCU` 被 ACL 锁死时死登记无法清理。以上均记录在 `docs/acceptance-plan.md`。
